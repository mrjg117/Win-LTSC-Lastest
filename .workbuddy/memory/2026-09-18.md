   - GitHub Actions **公开仓库免费**（Windows runner含内，无额度焦虑）。
   - Git LFS(10GiB存/10GiB带宽/月)与我们无关——ISO不进git，只进Release资产+私有桶。
   - CF R2 免费=10 GB-month存储 + 1M ClassA + 10M ClassB + egress免费；5GB ISO×3版>10GB → 免费仅够~1-2版。用户可能不用R2（仅作他人引用分发镜像）。
   - OneDrive: rclone/Graph，可选。
   - **每端保留版本数独立可配**: KEEP_RELEASE / KEEP_R2 / KEEP_ONEDRIVE（非全局X）。
   - 三端功能齐全，上传各自开关 UPLOAD_RELEASE / UPLOAD_R2 / UPLOAD_ONEDRIVE。

4. 配置口全开: 所有开关走 workflow_dispatch 输入 + 配置文件，随时可改。
5. 脚本落点: 首启脚本放 C:\PostSetup\（明显位置，用户可删）。触发用**setupcomplete.cmd**薄引导(装完自动跑一次、自删)，**不用计划任务、不建服务**。可选"全手动"模式=只把脚本放进C:\PostSetup不自动跑。

10. 本轮细化(IoT当桌面用 + 实测需求, 见对话):
   - 用户确用 IoT Enterprise LTSC（Win10 2021/19044 与 Win11 2024/26100 都做），当桌面版用，非工控。
   - 远程桌面必用 → 不删 RDP 客户端(mstsc, 核心不在可移除列表)与 RDS 主机；IoT可移除包中仅 RemoteDesktopServices-Collaboration(协作/共享,~1.46MB)属RDS家族，为安全 KEEP。
   - IE模式必用 → 内核来自 OS MSHTML/IE 引擎，非 Edge 内嵌。Win10 IoT 移除 IE11 可选功能会连带使 Edge IE模式失效(微软官方确认) → Win10 构建 KEEP IE11；Win11 IoT 因 MSHTML 由 OS 保留，移除 IE11 app 后 IE模式仍可用 → Win11 构建可移除 IE11 app。
   - WMP: 移除旧版，改由 Store 离线 provision 新版 Media Player。
   - 打印(Internet Printing Client) + 文件同步(Work Folders) KEEP。
   - XPS 使用率极低 → 默认 REMOVE。

## baseline 命名契约（已锁定，勿随意改）
- 消费端 build_iso.yml 拉基线用 `gh release download baseline --pattern "*$branch.7z.*"` 再 `7z x 首卷`。故**分卷命名必须含分支号且以 .7z. 结尾**。
- 约定: `baseline-<分支>.7z.001 … .00N`（例 baseline-26100.7z.001），每块 `-v1900m`（≤1.9GiB 规避 Release 2GiB 硬限）。卷内 ISO 保留微软原名（便于追溯），构建时重命名为 baseline-<分支>.iso。
- 配套: `baseline.manifest.json`（每分支 isoName/已验SHA256/来源URL/各分卷名+分卷SHA256）+ `SHA256SUMS`（GNU 格式，分卷速校）。Release 标签固定 `baseline`，上传用 `--clobber` 覆盖。
- SHA256 单一真相源 = config.yml 的 `baseline.sha256.<分支>`（64hex）；拉取/构建均强制比对，不符即中止。
- 本轮新增(本地未推送): `tools/fetch-baseline.py`(拉取/校验/分包/上传逻辑) + `.github/workflows/fetch-baseline.yml`(手动 workflow_dispatch, ubuntu-latest + p7zip-full) + `baseline-sources.json`(各分支权威分发源 URL，含 REPLACE 占位符，用户填真实直链)。期望 SHA256 仍占位 → 跑前必须先填 config.yml。
- 修 bug: 原 `tools/upload-baseline.ps1` 按 ISO 原名做卷名(不含分支号)，build_iso.yml 匹配不到；已改为 `baseline-$Branch.7z` 同套命名。
